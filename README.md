# صقور العراق — Android أصلي

هذا مشروع Android أصلي بـKotlin وMapLibre Native، وليس WebView. النسخة الحالية تعرض خريطة تفاعلية لبغداد وتحدد موقع الجهاز عند منح إذن GPS.

## بناء APK

يمكن فتح المجلد في Android Studio ومزامنة Gradle ثم تشغيل `assembleDebug`. كما يمكن رفع المشروع إلى مستودع GitHub وتشغيل إجراء **Build Android APK** من تبويب Actions؛ سينشر ملف APK كـartifact باسم `sqoor-native-debug-apk`.

## النطاق الحالي

هذه قاعدة أصلية للخريطة والموقع فقط. البحث والمسارات والتنبيهات والمشاركة وبقية وظائف صفحة الويب لم تُنقل بعد، كما أن صور المركبات المشار إليها في الصفحة غير موجودة حالياً في مجلد `assets` على سطح المكتب.
